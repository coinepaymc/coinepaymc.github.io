# AWS คืออะไร?

Amazon Web Services (AWS) คือแพลตฟอร์มคลาวด์ของ Amazon ที่ให้บริการทรัพยากรคอมพิวเตอร์แบบ On-demand สำหรับนักพัฒนา บริษัท และองค์กรต่าง ๆ

บริการหลักของ AWS ได้แก่:

- เซิร์ฟเวอร์คลาวด์ EC2;
- พื้นที่จัดเก็บข้อมูลแบบ Object Storage S3;
- บริการฐานข้อมูล RDS;
- ระบบ Serverless Computing Lambda;
- CDN CloudFront;
- บริการ AI และ Machine Learning;
- โซลูชันด้านเครือข่ายและความปลอดภัย

แทนที่จะซื้อเซิร์ฟเวอร์จริง ผู้ใช้สามารถเช่าทรัพยากรคลาวด์และชำระเงินตามการใช้งานจริง

# การใช้งานทั่วไปของ AWS

## 1. การโฮสต์เว็บไซต์และแอปพลิเคชัน

- บริการ API

---

## 2. โปรเจกต์ AI และ Machine Learning

AWS ให้บริการด้าน AI ที่สามารถใช้สำหรับ:

- การฝึกโมเดล;

- การวิเคราะห์ข้อมูล;

AWS นิยมใช้สำหรับ:

- จัดการข้อมูลขององค์กร;
- ประมวลผลข้อมูลขนาดใหญ่
