# Como adicionar pagamento para o Claude API?

A interface pode mudar conforme a conta e região. Os passos abaixo são uma referência geral.

## Passo 1: Entrar no Anthropic Console

Acesse sua conta Anthropic e abra o painel de desenvolvedor.

Verifique se:

- Sua conta está ativa;
- O acesso à API está disponível;
- Você consegue acessar as configurações de Billing.

---

## Passo 2: Abrir as configurações de Billing

Procure opções semelhantes a:

- Billing;
- Payment;
- Add Payment Method;
- Credit Card.

O nome exato pode variar.

---

## Passo 3: Adicionar um cartão de pagamento

Informe os dados solicitados:

- Número do cartão;
- Data de validade;
- CVV;
- Nome do titular;
- Endereço de cobrança.

Certifique-se de que as informações correspondem aos dados fornecidos pelo provedor do cartão.

---

## Passo 4: Concluir a verificação do pagamento

A Anthropic ou o provedor de pagamento pode realizar:

- Verificação do cartão;
- Autorização temporária;
- Verificações de segurança;
- Confirmação do pagamento.

Após a aprovação, você poderá usar o Claude API conforme as configurações de cobrança.

# Problemas comuns de pagamento no Claude API

## 1. O cartão não permite pagamentos internacionais

Alguns cartões possuem pagamentos internacionais desativados.

Verifique:

- Configurações de pagamento internacional;
- Permissões para compras online;
- Compatibilidade com comerciantes estrangeiros.

---

## 2. Limitações do tipo de cartão

Nem todos os cartões aceitam:

- Serviços de API;
- Produtos digitais;
- Cobranças automáticas;
- Assinaturas de software.

A compatibilidade depende do sistema de pagamento utilizado.

---

## 3. Informações de cobrança incorretas

Os pagamentos podem falhar devido a:

- Nome incorreto;
- Endereço de cobrança incorreto;
- Diferença de região;
- Dados do cartão incorretos.

---

## 4. Problemas com verificações de segurança

Muitas tentativas de pagamento falhas ou mudanças frequentes de cartão podem ativar verificações adicionais.
