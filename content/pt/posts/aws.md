# O que é a AWS?

Amazon Web Services (AWS) é a plataforma de computação em nuvem da Amazon que fornece recursos cloud sob demanda para desenvolvedores, empresas e organizações.

A AWS oferece diversos serviços, incluindo:

- Servidores cloud EC2;
- Armazenamento de objetos S3;
- Serviços de banco de dados RDS;
- Computação sem servidor Lambda;
- CDN CloudFront;
- Serviços de inteligência artificial e machine learning;
- Soluções de rede e segurança.

Em vez de comprar servidores físicos, os usuários podem alugar recursos cloud e pagar conforme o uso real.

# Problemas comuns de pagamento na AWS

## 1. O cartão não suporta pagamentos internacionais

Verifique:

- Configurações de pagamento internacional;
- Permissões para transações online;
- Compatibilidade com comerciantes estrangeiros.

---

## 2. O cartão não suporta serviços cloud

Alguns cartões podem limitar:

- Serviços de computação em nuvem;
- Serviços digitais;
- Pagamentos automáticos.

---

## 3. Informações de cobrança incorretas

Confirme:

- Nome do titular;
- Endereço de cobrança;
- País ou região;
- Dados do cartão.

---

## 4. Verificação de segurança da conta AWS

A AWS pode realizar verificações adicionais dependendo da atividade da conta.

Exemplos:

- Contas novas;
- Atividade de login incomum;
- Vários pagamentos falhos.

Recomendações:

- Verifique o status da conta;
- Confirme as informações de pagamento;
- Evite repetir tentativas de pagamento malsucedidas.

# Dicas de segurança para AWS

## Controlar custos cloud

Boas práticas:

- Exclua servidores que não utiliza;
- Pare recursos ociosos;
- Revise as faturas regularmente;
- Configure alertas de orçamento.

---

## Proteger informações da conta AWS

Nunca compartilhe:

- Senha da AWS;
- Access Key;
- Secret Key;
- Informações de acesso ao servidor.

Recomendações:

- Ative a autenticação multifator (MFA);
- Revise as permissões da conta regularmente.

---

## Utilizar serviços oficiais

Recomendações:

- Cadastre-se pela plataforma oficial da AWS;
- Evite contas compartilhadas de origem desconhecida;
- Verifique as configurações de segurança regularmente.
