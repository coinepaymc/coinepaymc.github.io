# AWS क्या है?

Amazon Web Services (AWS) Amazon द्वारा प्रदान किया गया एक क्लाउड प्लेटफॉर्म है, जो डेवलपर्स, कंपनियों और संगठनों को ऑन-डिमांड क्लाउड संसाधन उपलब्ध कराता है।

AWS कई सेवाएं प्रदान करता है, जिनमें शामिल हैं:

- EC2 क्लाउड सर्वर;
- S3 ऑब्जेक्ट स्टोरेज;
- RDS डेटाबेस सेवाएं;
- Lambda सर्वरलेस कंप्यूटिंग;
- CloudFront CDN;
- AI और मशीन लर्निंग सेवाएं;
- नेटवर्क और सुरक्षा समाधान।

भौतिक सर्वर खरीदने के बजाय, उपयोगकर्ता क्लाउड संसाधनों को किराए पर ले सकते हैं और वास्तविक उपयोग के अनुसार भुगतान कर सकते हैं।
