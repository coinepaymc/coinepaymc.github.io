# What Is AWS?

Amazon Web Services (AWS) is Amazon's cloud computing platform that provides on-demand cloud resources for developers, businesses, and organizations.

AWS offers many services, including:

- EC2 cloud servers;
- S3 object storage;
- RDS database services;
- Lambda serverless computing;
- CloudFront CDN;
- AI and machine learning services;
- Networking and security solutions.

Instead of purchasing physical servers, users can rent cloud resources and pay based on actual usage.
