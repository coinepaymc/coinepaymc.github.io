# Cum adaugi plata pentru Claude API?

Interfața poate fi diferită în funcție de cont și regiune. Pașii de mai jos sunt orientativi.

## Pasul 1: Conectează-te la Anthropic Console

Accesează contul Anthropic și deschide panoul pentru dezvoltatori.

Verifică dacă:

- Contul este activ;
- Accesul API este disponibil;
- Poți accesa setările Billing.

---

## Pasul 2: Deschide setările Billing

Caută opțiuni precum:

- Billing;
- Payment;
- Add Payment Method;
- Credit Card.

Denumirea exactă poate varia.

---

## Pasul 3: Adaugă un card de plată

Introdu informațiile solicitate:

- Numărul cardului;
- Data expirării;
- CVV;
- Numele titularului;
- Adresa de facturare.

Asigură-te că informațiile corespund datelor furnizate de furnizorul cardului.

---

## Pasul 4: Finalizează verificarea plății

Anthropic sau furnizorul de plată poate efectua:

- Verificarea cardului;
- Autorizare temporară;
- Verificări de securitate;
- Confirmarea plății.

După aprobarea plății, poți utiliza Claude API conform setărilor de facturare.

# Probleme frecvente de plată pentru Claude API

## 1. Cardul nu permite plăți internaționale

Unele carduri au plățile internaționale dezactivate implicit.

Verifică:

- Setările pentru plăți internaționale;
- Permisiunile pentru cumpărături online;
- Compatibilitatea cu comercianții externi.

---

## 2. Limitări ale tipului de card

Nu toate cardurile acceptă:

- Servicii API;
- Produse digitale;
- Plăți automate;
- Abonamente software.

Compatibilitatea depinde de sistemul de plată utilizat.

---

## 3. Date de facturare incorecte

Plata poate eșua din cauza:

- Numelui incorect;
- Adresei de facturare greșite;
- Diferențelor de regiune;
- Datelor incorecte ale cardului.

---

## 4. Probleme cu verificările de securitate

Mai multe încercări eșuate de plată sau schimbarea frecventă a cardurilor pot activa verificări suplimentare.
