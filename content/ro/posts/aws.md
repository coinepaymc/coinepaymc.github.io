# Ce este AWS?

Amazon Web Services (AWS) este platforma cloud a Amazon care oferă resurse de calcul la cerere pentru dezvoltatori, companii și organizații.

AWS oferă numeroase servicii, inclusiv:

- Servere cloud EC2;
- Stocare obiect S3;
- Servicii de baze de date RDS;
- Calcul fără server Lambda;
- CDN CloudFront;
- Servicii de inteligență artificială și machine learning;
- Soluții de rețea și securitate.

În loc să cumpere servere fizice, utilizatorii pot închiria resurse cloud și pot plăti în funcție de utilizarea reală.

# Sfaturi de securitate pentru AWS

## Controlează costurile cloud

Practici recomandate:

- Șterge serverele neutilizate;
- Oprește resursele inactive;
- Verifică regulat facturile;
- Configurează alerte de buget.

---

## Protejează informațiile contului AWS

Nu distribui niciodată:

- Parola AWS;
- Access Key;
- Secret Key;
- Informații de acces la server.

Recomandări:

- Activează autentificarea multifactor (MFA);
- Verifică periodic permisiunile contului.

---

## Folosește servicii oficiale

Recomandări:

- Înregistrează-te prin platforma oficială AWS;
- Evită conturile partajate din surse necunoscute;
- Verifică regulat setările de securitate.
