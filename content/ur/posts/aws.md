# AWS کیا ہے؟

Amazon Web Services (AWS) Amazon کی فراہم کردہ ایک کلاؤڈ پلیٹ فارم سروس ہے، جو ڈویلپرز، کمپنیوں اور اداروں کو آن ڈیمانڈ کلاؤڈ وسائل فراہم کرتی ہے۔

AWS کی اہم سروسز میں شامل ہیں:

- EC2 کلاؤڈ سرورز؛
- S3 آبجیکٹ اسٹوریج؛
- RDS ڈیٹا بیس سروسز؛
- Lambda سرور لیس کمپیوٹنگ؛
- CloudFront CDN؛
- AI اور مشین لرننگ سروسز؛
- نیٹ ورک اور سیکیورٹی حل۔

فزیکل سرور خریدنے کے بجائے صارفین کلاؤڈ وسائل کرائے پر لے سکتے ہیں اور اصل استعمال کے مطابق ادائیگی کر سکتے ہیں۔
