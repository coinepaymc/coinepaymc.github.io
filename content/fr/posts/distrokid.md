# 3. Comment payer les services DistroKid avec une carte de crédit virtuelle ?

Certaines cartes bancaires peuvent limiter les transactions internationales.

Causes possibles :

- Fonction de paiement international désactivée ;
- Politiques de contrôle des risques bancaires ;
- Restrictions régionales.

---

## 2. Informations d’adresse de facturation incorrectes

Les plateformes internationales vérifient généralement les informations de paiement.

Erreurs fréquentes :

- Format d’adresse incorrect ;
- Code postal incorrect ;
- Mauvaise sélection du pays.

Lors de la saisie des informations de facturation, assurez-vous qu’elles correspondent aux exigences de la plateforme.

## 3. Solde insuffisant sur la carte

Les paiements internationaux par abonnement peuvent inclure :

- Frais de service ;
- Frais de conversion de devises ;
- Frais de traitement du paiement.

Assurez-vous que votre carte dispose d’un solde suffisant avant d’effectuer le paiement.

## 4. Échec de la vérification de sécurité de la plateforme

Causes possibles :

- Nouvelle méthode de paiement ;

- Plusieurs tentatives de paiement échouées ;
