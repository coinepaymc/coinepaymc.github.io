# Qu’est-ce qu’eBay ?

eBay est une marketplace mondiale permettant aux utilisateurs d’acheter et de vendre différents types de produits.

eBay propose principalement deux méthodes d’achat :

- **Auction (Enchères)**
- **Buy It Now (Achat immédiat)**

Les catégories de produits courantes comprennent :

- Téléphones, ordinateurs et produits électroniques ;
- Appareils photo et équipements photographiques ;
- Produits gaming et objets de collection ;
- Vêtements, chaussures et accessoires ;
- Articles pour la maison ;
- Pièces automobiles ;
- Équipements industriels ;
- Produits rares et d’occasion.

Contrairement aux plateformes e-commerce traditionnelles, eBay propose des produits provenant de vendeurs particuliers, de marques et de boutiques professionnelles.

# Comment payer une commande eBay avec une carte ?

Le processus peut varier selon la région et le compte utilisateur.

## Étape 1 : Se connecter à eBay

Ouvrez le site officiel ou l’application eBay.

Connectez-vous à votre compte et sélectionnez le produit à acheter.

---

## Étape 2 : Vérifier les informations du produit

Avant l’achat, vérifiez :

- La description du produit ;
- Les évaluations du vendeur ;
- Les images du produit ;
- Le mode de livraison ;
- La politique de retour ;
- Le lieu d’expédition du produit.

---

## Étape 3 : Accéder au paiement

Sélectionnez :

- Add to Cart (Ajouter au panier) ;
- Buy It Now (Acheter maintenant) ;
- Checkout (Finaliser l’achat).

---

## Étape 4 : Choisir le moyen de paiement

Sélectionnez les options disponibles :

- Credit Card ;
- Debit Card ;
- PayPal ;
- Autres moyens de paiement.

---

## Étape 5 : Saisir les informations de carte

Les informations demandées peuvent inclure :

- Numéro de carte ;
- Date d’expiration ;
- CVV ;
- Nom du titulaire ;
- Adresse de facturation.

Les informations doivent correspondre aux données fournies par votre prestataire de paiement.

---

## Étape 6 : Finaliser la vérification du paiement

Le paiement peut nécessiter :

- Une vérification bancaire ;
- Une authentification 3D Secure ;
- Une petite autorisation temporaire ;
- Un contrôle de sécurité.

Après un paiement réussi, vous pouvez consulter :

- Le statut de la commande ;
- Les informations d’expédition ;
- Le suivi du colis.

Vérifiez :

- Les paramètres de paiement international ;
- Les autorisations de transactions en ligne ;
- La compatibilité avec les commerçants étrangers.

## 2. La carte ne prend pas en charge les transactions e-commerce

Certaines cartes peuvent limiter :

- Les achats internationaux ;

## 3. Les informations de facturation ne correspondent pas

Les paiements peuvent échouer à cause de :

- Nom incorrect ;
- Adresse différente ;
- Région incompatible ;
- Informations de carte incorrectes.

## 4. Vérification de sécurité du compte

eBay peut effectuer des contrôles supplémentaires dans certains cas :

- Nouveaux comptes ;
- Commandes importantes ;
- Activité de connexion inhabituelle ;
- Plusieurs paiements échoués.
