# Comment payer Facebook Ads avec une carte ?

Le processus peut varier selon la région et le compte Meta Ads.

## Étape 1 : Ouvrir Meta Ads Manager

Connectez-vous à votre compte Facebook ou Meta Business.

Ouvrez le Gestionnaire de publicités.

---

## Étape 2 : Créer un compte publicitaire

Configurez :

- Le nom du compte publicitaire ;
- Le fuseau horaire ;
- La devise ;
- Les informations commerciales.

---

## Étape 3 : Ajouter un moyen de paiement

Accédez à :

**Billing (Facturation)**

Sélectionnez :

**Add Payment Method (Ajouter un moyen de paiement)**

---

## Étape 4 : Saisir les informations de carte

Vous devrez peut-être fournir :

- Le numéro de carte ;
- La date d’expiration ;
- Le CVV ;
- Les informations du titulaire ;
- L’adresse de facturation.

---

## Étape 5 : Effectuer la vérification

Meta peut effectuer :

- Une vérification bancaire ;
- De petites autorisations ;
- Des contrôles de sécurité.

Après validation, la carte peut être utilisée pour payer les campagnes publicitaires.
