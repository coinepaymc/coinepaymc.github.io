# 5. Raisons courantes d'un échec de paiement Steam

## 1. La carte ne prend pas en charge les paiements internationaux

Causes possibles :

- Restrictions régionales ;
- Transactions internationales désactivées ;
- Limitations de l'émetteur de la carte.

---

## 2. Informations de facturation incorrectes

Problèmes fréquents :

- Nom incorrect ;
- Adresse non correspondante ;
- Code postal incorrect ;
- Pays ou région différent.

Des informations incorrectes peuvent entraîner :

- Un échec du paiement ;
- Une vérification de sécurité ;
- L'annulation de la transaction.

---

## 3. Solde insuffisant

Causes possibles :

- Prix du jeu ;
- Variation du taux de change ;
- Frais de transaction internationale.

Assurez-vous que le moyen de paiement dispose d'un solde suffisant avant l'achat.

---

## 4. Vérification de sécurité du paiement

Certaines transactions peuvent nécessiter une vérification supplémentaire.

Raisons possibles :

- Nouveau moyen de paiement ;
- Activité inhabituelle ;
- Contrôles de sécurité du compte.
