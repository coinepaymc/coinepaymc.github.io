# Qu’est-ce que Calilio ?

Calilio est un **système de téléphonie professionnelle basé sur le cloud**.

Après avoir créé un compte, les utilisateurs peuvent gérer leurs numéros virtuels depuis le web ou un appareil mobile et communiquer via Internet.

Les principales fonctionnalités peuvent inclure :

- Numéros de téléphone virtuels ;
- Appels entrants et sortants ;
- Messages SMS ;
- Call Forwarding ;
- Call Recording ;
- Voicemail ;
- Numéros partagés entre plusieurs membres d’une équipe ;
- Call Analytics ;
- Fonctions IVR et centre d’appels sur certains forfaits.

Calilio peut être utilisé aussi bien par des particuliers ayant besoin d’un deuxième numéro international que par des entreprises qui gèrent le service client, les ventes internationales ou des équipes à distance.

# À quoi sert un numéro virtuel Calilio ?

## Numéro professionnel international

Les entreprises peuvent utiliser des numéros virtuels aux États-Unis, au Canada et dans d’autres pays pris en charge.

Cela permet à une équipe de disposer d’un numéro professionnel local même si ses employés se trouvent dans un autre pays.

## Service client

Les équipes peuvent partager des numéros et les utiliser pour :

- Recevoir les appels des clients ;
- Consulter l’historique des appels ;
- Transférer les appels ;
- Gérer les messages vocaux ;
- Attribuer les appels à différents membres de l’équipe.

## Communication des équipes internationales

Pour les équipes réparties dans plusieurs pays, Calilio peut centraliser les appels, les messages et les communications internes dans un seul système.

# Forfaits et tarifs de Calilio

Calilio propose différents forfaits, notamment Standard, Premium et Enterprise.

Le prix dépend du forfait choisi, du cycle de facturation, du nombre d’utilisateurs et des fonctionnalités nécessaires.

Il faut garder à l’esprit que :

**Le prix de l’abonnement ne signifie pas nécessairement que les appels et les messages sont illimités.**

Les forfaits peuvent inclure un certain volume d’appels et de messages, tandis que l’utilisation supplémentaire peut être facturée séparément depuis le solde Wallet.

Les numéros virtuels peuvent également entraîner des frais récurrents supplémentaires.

Avant de souscrire, vérifiez :

- Le prix du forfait ;
- Le prix du numéro virtuel ;
- Les tarifs des appels ;
- Les frais SMS ;
- La disponibilité dans le pays souhaité.

# Que faire si le paiement Calilio échoue ?

## Les paiements internationaux sont désactivés

Vérifiez si votre carte prend en charge :

- Les paiements internationaux ;
- Les paiements en ligne ;
- Les transactions en devises étrangères.

## Informations de Billing incorrectes

Vérifiez :

- Le nom du titulaire ;
- La Billing Address ;
- Le code postal ;
- Le pays ou la région.

## Solde insuffisant

Les frais Calilio peuvent inclure davantage que le simple abonnement.

Il peut également y avoir des coûts liés à :

- Des numéros virtuels ;
- L’utilisation des appels ;
- L’utilisation des SMS ;
- Des recharges de Wallet.

Conserver un peu de solde supplémentaire peut aider à éviter certains échecs de paiement.

## Trop de tentatives de paiement

Si une transaction a déjà été refusée, évitez de répéter le même paiement plusieurs fois sur une courte période.

Vérifiez d’abord l’état de la carte et les informations de Billing avant de réessayer.
