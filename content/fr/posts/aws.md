# Qu’est-ce qu’AWS ?

Amazon Web Services (AWS) est la plateforme cloud d’Amazon qui fournit des ressources informatiques à la demande pour les développeurs, les entreprises et les organisations.

AWS propose de nombreux services, notamment :

- Serveurs cloud EC2 ;
- Stockage objet S3 ;
- Services de bases de données RDS ;
- Calcul sans serveur Lambda ;
- CDN CloudFront ;
- Services d’intelligence artificielle et de machine learning ;
- Solutions réseau et sécurité.

Au lieu d’acheter des serveurs physiques, les utilisateurs peuvent louer des ressources cloud et payer selon leur utilisation réelle.

## 1. La carte ne prend pas en charge les paiements internationaux

Vérifiez :

- Les paramètres de paiement international ;
- Les autorisations de transactions en ligne ;
- La compatibilité avec les commerçants étrangers.

## 2. La carte ne prend pas en charge les services cloud

Certaines cartes peuvent limiter :

- Les services de cloud computing ;
- Les services numériques ;
- Les paiements automatiques.

---

## 3. Informations de facturation incorrectes

Confirmez :

- Le nom du titulaire ;
- L’adresse de facturation ;
- Le pays ou la région ;
- Les informations de la carte.

---

## 4. Vérification de sécurité du compte AWS

AWS peut effectuer des contrôles supplémentaires selon l’activité du compte.

Exemples :

- Nouveaux comptes ;
- Activité de connexion inhabituelle ;
- Plusieurs paiements échoués.

Recommandations :

- Vérifiez l’état du compte ;
- Confirmez les informations de paiement ;
- Évitez les tentatives répétées de paiement échouées.

# Conseils de sécurité pour AWS

## Contrôler les coûts cloud

Bonnes pratiques :

- Supprimez les serveurs inutilisés ;
- Arrêtez les ressources inactives ;
- Consultez régulièrement les factures ;
- Configurez des alertes de budget.

---

## Protéger les informations du compte AWS

Ne partagez jamais :

- Le mot de passe AWS ;
- L’Access Key ;
- La Secret Key ;
- Les informations de connexion au serveur.

Recommandations :

- Activez l’authentification multifactorielle (MFA) ;
- Vérifiez régulièrement les autorisations du compte.

---

## Utiliser les services officiels

Recommandations :

- Inscrivez-vous via la plateforme officielle AWS ;
- Évitez les comptes partagés provenant de sources inconnues ;
- Vérifiez régulièrement les paramètres de sécurité.
