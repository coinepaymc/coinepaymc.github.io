# Czym jest AWS?

Amazon Web Services (AWS) to platforma chmurowa firmy Amazon, która zapewnia zasoby cloud na żądanie dla programistów, firm i organizacji.

AWS oferuje wiele usług, takich jak:

- Serwery cloud EC2;
- Magazyn obiektowy S3;
- Usługi baz danych RDS;
- Bezserwerowe przetwarzanie Lambda;
- CDN CloudFront;
- Usługi sztucznej inteligencji i machine learning;
- Rozwiązania sieciowe i bezpieczeństwa.

Zamiast kupować fizyczne serwery, użytkownicy mogą wynajmować zasoby cloud i płacić zgodnie z rzeczywistym wykorzystaniem.
