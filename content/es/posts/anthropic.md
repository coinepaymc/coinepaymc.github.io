# Cómo añadir un método de pago para Claude API

La interfaz puede cambiar según la cuenta o región. Los siguientes pasos son una referencia general.

## Paso 1: Iniciar sesión en Anthropic Console

Accede a tu cuenta de Anthropic y abre el panel de desarrollador.

Comprueba que:

- La cuenta está activa;
- El acceso a API está disponible;
- Puedes acceder a la configuración de Billing.

---

## Paso 2: Abrir la configuración de Billing

Busca opciones similares a:

- Billing;
- Payment;
- Add Payment Method;
- Credit Card.

El nombre exacto puede variar.

---

## Paso 3: Añadir una tarjeta de pago

Introduce la información solicitada:

- Número de tarjeta;
- Fecha de vencimiento;
- CVV;
- Nombre del titular;
- Dirección de facturación.

Asegúrate de que la información coincide con los datos proporcionados por el proveedor de la tarjeta.

---

## Paso 4: Completar la verificación del pago

Anthropic o el proveedor de pagos pueden realizar:

- Verificación de tarjeta;
- Autorización temporal;
- Controles de seguridad;
- Confirmación del pago.

Después de la verificación, podrás utilizar Claude API según la configuración de facturación.

- Configuración de pagos internacionales;

- Compatibilidad con comercios extranjeros.

---

## 2. Limitaciones del tipo de tarjeta

No todas las tarjetas admiten:

- Servicios API;
- Productos digitales;
- Cobros automáticos;
- Suscripciones de software.

La compatibilidad depende del sistema de pago utilizado.

## 3. Información de facturación incorrecta

Los pagos pueden fallar debido a:
