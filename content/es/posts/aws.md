# ¿Qué es AWS?

Amazon Web Services (AWS) es la plataforma de computación en la nube de Amazon que proporciona recursos cloud bajo demanda para desarrolladores, empresas y organizaciones.

AWS ofrece numerosos servicios, incluyendo:

- Servidores cloud EC2;
- Almacenamiento de objetos S3;
- Servicios de bases de datos RDS;
- Computación sin servidor Lambda;
- CDN CloudFront;
- Servicios de inteligencia artificial y machine learning;
- Soluciones de red y seguridad.

En lugar de comprar servidores físicos, los usuarios pueden alquilar recursos cloud y pagar según el uso real.
