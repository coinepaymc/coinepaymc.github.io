# 一、TakeProfitTrader是什么？

TakeProfitTrader 采用比较典型的 Prop Firm 模式。

用户先购买测试账户，通过模拟交易证明自己的交易能力和风险管理水平，而不是直接获得真实资金账户。

整个过程主要包括：

- 选择 Test Account；
- 完成规定的 Profit Target；
- 遵守 Drawdown 和 Consistency 等规则；
- 通过 Evaluation；
- 进入 PRO；
- 后续符合要求时进入 PRO+。

不同账户规模对应不同的盈利目标、最大仓位和风险限制，因此选择账户时不建议只看 25K、50K、100K 或 150K 这样的名义金额。

# 二、Test、PRO和PRO+分别是什么？

## Test Account

Test 是 TakeProfitTrader 的 Evaluation 阶段。

这个阶段属于模拟交易，主要目的是完成平台规定的测试。

需要重点关注：

- Profit Target；
- Drawdown；
- Consistency；
- 最大持仓；
- 允许交易的产品；
- 最低交易天数。

目前新 Test Account 的最低交易日为 **3个交易日**。

不过，3天只是最低时间要求，并不意味着交易3天就自动通过。Profit Target 和其他风险规则仍然需要同时满足。

---

## PRO Account

通过 Test 后会进入 PRO。

PRO 仍然属于模拟交易环境，但符合规则的利润已经可以申请收益提取。

目前主要规则包括：

- 交易者获得符合条件利润的 **80%**；
- 平台获得 **20%**；
- 支持符合条件后的 Day-One Payout；
- 可以申请 Daily Payout；
- 存在 Buffer Zone 要求。

因此，PRO 阶段除了盈利之外，还要特别注意 Buffer 和 Drawdown 对账户的影响。

---

## PRO+ Account

PRO+ 是更进一步的账户阶段，进入真实市场交易环境。

目前主要特点包括：

- 属于 Live Market；
- 交易者获得符合条件利润的 **90%**；
- 平台获得 **10%**；
- 没有 PRO 阶段相同的 Buffer Zone 要求；
- 支持 Daily Payout。

PRO 用户并不是自己点击就可以直接升级到 PRO+，通常还需要根据交易表现、风险控制和交易行为进行评估。

# 三、TakeProfitTrader测试最需要注意什么？

很多新用户只关注 Profit Target，但真正影响能否顺利通过测试的往往还有其他规则。

## Profit Target

不同账户规模有不同的盈利目标。

选择账户时应该根据自己的交易策略、平均盈利能力和风险承受范围决定，而不是单纯追求更大的账户金额。

## Drawdown

Drawdown 是 Prop Firm 交易中非常重要的风险限制。

如果账户亏损达到规定范围，即使之前已经有盈利，也可能导致测试失败或账户失效。

因此每次交易都应该考虑：

**如果这笔交易亏损，账户还剩多少风险空间。**

## Consistency

Test Account 还需要注意盈利一致性。

如果过度依赖某一天的大额盈利，可能影响测试进度。

相比通过一次重仓完成目标，更稳定的盈利通常更容易适应 Prop Firm 的交易规则。

# 四、Buffer Zone和出金规则

进入 PRO 后，需要重点理解 Buffer Zone。

Buffer 可以简单理解为账户需要保留的一部分安全空间。

即使账户已经盈利，也不代表全部利润都可以立即提取。申请出金时还需要考虑：

- 当前账户余额；
- Buffer；
- Drawdown；
- 可提取利润；
- 提款后剩余的风险空间。

TakeProfitTrader 目前比较有代表性的特点是 **Day-One & Daily Payout**。

也就是说，在符合条件后，PRO 用户可以较早申请收益提取，并且不需要等待固定的月度出金窗口。

PRO+ 同样支持 Daily Payout。

# 七、付款失败怎么办？

## 银行卡不支持国际支付

检查是否开启：

- International Payment；
- Online Payment；
- Foreign Currency Transaction。

## Billing信息不正确

重点检查：

- 持卡人姓名；
- Billing Address；
- Postal Code；
- 国家或地区。

## 卡片余额不足

除了订单金额，还可能受到汇率、预授权或卡片费用影响，因此建议适当保留额外余额。

## 连续付款失败

如果已经出现 Declined，不建议短时间内不断重复提交或频繁更换卡片。

先确认原因，再重新付款，可以减少额外触发支付风控的可能。
