# 一、AWS是什么？

Amazon Web Services（AWS）是亚马逊旗下的云计算服务平台，为个人开发者、企业和机构提供按需使用的云计算资源。

AWS 提供的主要服务包括：

- EC2 云服务器；
- S3 对象存储；
- RDS 数据库服务；
- Lambda 无服务器计算；
- CloudFront CDN加速；
- AI与机器学习服务；
- 网络和安全服务。

用户无需购买实体服务器，可以根据业务需求租用云资源，并按照实际使用量付费。
