# 一、Dynadot 是什么？

Dynadot 是一家提供域名注册和数字资产管理服务的平台。

主要服务包括：

## 1. 域名注册

用户可以注册不同类型的域名，例如：

- .com
- .net
- .org
- 国家地区域名
- 新顶级域名（New gTLD）

适用于：

- 企业网站；
- 独立站；
- 品牌官网；
- 产品页面；
- 项目网站。

## 2. 域名续费

域名通常需要定期续费。

用户可以管理：

- 域名到期时间；
- 自动续费设置；
- 续费价格；
- 域名状态。

## 3. 域名转入和转出

Dynadot 支持用户管理域名迁移，例如：

- 从其他注册商转入；
- 转移到其他注册商；
- 管理域名授权码。

## 4. DNS 管理

用户可以配置：

- A 记录；
- CNAME；
- MX 记录；
- TXT 记录；
- 子域名解析。

DNS 设置会影响：

- 网站访问；
- 邮箱服务；
- API 服务；
- 第三方验证。

## 5. 其他数字服务

包括：

- SSL 相关服务；
- 邮箱服务；
- 网站工具；
- 域名市场交易。

# 五、Dynadot 付款失败常见原因

## 1. 卡片余额不足

可能原因：

- 域名注册费用；
- 续费费用；
- 汇率变化；
- 国际交易手续费。

---

## 2. 卡片不支持域名服务

部分付款方式可能不支持：

- 域名注册商；
- 海外数字服务；
- 自动续费。

---

## 3. 账单信息不匹配

可能导致：

- 支付失败；
- 风控审核；
- 交易拒绝。

检查：

- 姓名；
- 地址；
- 国家地区。

---

## 4. 自动续费失败

域名通常需要长期维护。

自动续费失败可能导致：

- 域名过期；
- 网站无法访问；
- 邮箱服务异常。

建议定期检查：

- 域名到期时间；
- 自动续费状态；
- 付款方式有效期。
